# 🍔 Quick-Service Restaurant Sales Exploratory Analysis

## 🎯 Project Goal
The primary objective of this project was to conduct a detailed exploratory data analysis (EDA) of sales transactions to identify key performance indicators (KPIs), understand product performance, and uncover trends that can inform operational and marketing strategies.

## 📊 Key Findings & Insights
The analysis focused on understanding product category performance, revealing metrics such as:
* **Highest Revenue Drivers:** Products like 'Burgers' generate the highest average revenue per transaction ($7256.06 per average category transaction).
* **Volume Drivers:** Products like 'Beverages' and 'Fries' show high average quantity sold per transaction (699.20 and 627.76 respectively).
* **Profitability Mix:** Comparison of average quantity and revenue highlights which products drive volume versus high-value sales.

## 🛠️ Technologies & Tools Used
* **Data Analysis & Processing:** Python (Pandas)
* **Data Visualization:** Python (Matplotlib, Seaborn)
* **Data Source:** Microsoft Excel (`file.xlsx`)
* **Environment:** Jupyter Notebook
